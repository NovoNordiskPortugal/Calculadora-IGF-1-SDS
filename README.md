# Calculadora SDS IGF-1 — Pediatria e Adultos

## Como abrir

1. Descompactar a pasta ZIP.
2. Abrir `index.html` num browser moderno.
3. Preencher os campos obrigatórios e clicar em **Calcular Score SDS**.
4. O módulo opcional de somapacitano permite rever:
   - SDS calculado de IGF-1, mantendo a fórmula original;
   - ajuste pré-analítico do SDS por interpolação linear conforme a ferramenta anexa;
   - ajuste pós-dose de somapacitano apenas no contexto pediátrico/adolescente, quando aplicável;
   - orientação de próximo passo terapêutico baseada no RCM Sogroya e diretrizes anexas.
5. Clicar em **Descarregar PDF** para gerar o relatório.

## Notas de validação

- O cálculo SDS original foi mantido: média = (limite inferior + limite superior)/2, DP = (limite superior - limite inferior)/3,92, SDS = (IGF-1 - média)/DP.
- A correção pré-analítica usa os pontos fornecidos na ferramenta anexa e deve ser validada institucionalmente antes de utilização clínica.
- A orientação terapêutica é apoio à decisão e não prescreve autonomamente uma dose.
- Validar referências, algoritmo, dados de referência, privacidade, farmacovigilância e aprovação local/MLR antes de publicação.
